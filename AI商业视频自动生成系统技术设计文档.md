# AI商业视频自动生成系统技术设计文档

## 1. 项目概述

本项目旨在构建一个面向商业场景的 AI
视频自动生成平台。用户仅需要上传商品图片、人物素材、场景图片，并输入简单的视频需求，系统即可自动完成图片理解、营销策划、广告脚本生成、视频分镜设计、AI
视频生成、配音字幕生成以及最终视频合成。

系统定位不是单纯的"图片转视频工具"，而是一个基于多模态大模型与生成式 AI
Agent 的智能广告内容生产系统。

核心目标：

> 将传统需要摄影、模特、场景搭建、剪辑和文案策划的广告制作流程，转化为自动化
> AI 视频生产流水线。

# 5. AI Agent 系统设计

## 5.1 Vision Agent

负责理解上传图片。

输入：

商品图片、人物图片、环境图片。

输出结构化信息：

``` json
{
"product":{
"name":"children toy",
"material":"wood",
"color":"blue",
"features":["safe","educational"]
},

"character":{
"age":"5",
"emotion":"happy"
},

"scene":{
"location":"family living room",
"style":"warm"
}
}
```

推荐模型：

-   GPT Vision
-   Gemini Vision
-   Qwen-VL
-   InternVL

------------------------------------------------------------------------

# 5.2 Marketing Agent

负责商业营销分析。

功能：

-   分析目标用户
-   提炼卖点
-   设计广告策略
-   生成营销主题

输出：

``` json
{
"target_customer":"parents",
"selling_point":"creative development",
"emotion":"family happiness",
"hook":"child first successful creation"
}
```

------------------------------------------------------------------------

# 5.3 Script Agent

负责生成广告脚本。

例如：

15秒广告：

Scene 1：

孩子进入客厅发现玩具。

Scene 2：

孩子组装玩具。

Scene 3：

家庭互动展示产品。

------------------------------------------------------------------------

# 5.4 Storyboard Agent

将脚本转换为视频镜头。

输出：

``` json
{
"shot":1,
"time":"0-5s",
"camera":"wide shot",
"action":"child opens toy box",
"emotion":"excited"
}
```

包含：

-   镜头
-   动作
-   光线
-   摄影语言
-   情绪

------------------------------------------------------------------------

# 5.5 Prompt Optimization Agent

负责将普通描述转换为视频模型 Prompt。

适配：

-   Kling
-   Runway
-   Luma
-   Wan
-   HunyuanVideo

例如：

输入：

孩子玩玩具

输出：

A cinematic commercial advertisement, warm family living room, happy
child playing with toy, natural sunlight, professional product shot.

------------------------------------------------------------------------

# 5.6 Video Generation Agent

负责调用视频生成模型。

推荐 API：

-   Kling API
-   Runway API
-   Luma API

开源部署方向：

-   Wan2.1/Wan2.2
-   HunyuanVideo
-   CogVideoX

统一接口：

``` python
generate_video(
prompt,
reference_image,
duration,
style
)
```

------------------------------------------------------------------------

# 5.7 Quality Agent

负责自动评价生成结果。

检测：

-   商品一致性
-   人物一致性
-   视频稳定性
-   动作合理性
-   广告吸引力

低质量自动重新生成。
