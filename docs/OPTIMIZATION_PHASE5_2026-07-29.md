# FrameFlow 第五阶段优化记录（2026-07-29）

## 阶段目标

第五阶段建立正式视频供应商对照实验框架。在不调用付费 API 的前提下，先固定测试镜头、参考素材、质检维度、模型、价格依据和预算硬上限，避免直接在生产项目上反复试错。

## 官方能力核对

MiniMax 官方视频生成接口当前公开支持文生视频、图生视频、首尾帧视频和人物主体参考。视频任务采用“创建任务、轮询状态、根据文件 ID 下载”的异步流程。

- 视频生成文档：https://platform.minimaxi.com/docs/guides/video-generation
- 按量计费文档：https://platform.minimaxi.com/docs/guides/pricing-paygo
- 速率限制：https://platform.minimaxi.com/docs/guides/rate-limits

MiniMax Hailuo Fast 768P 6 秒的公开按量价格为 ¥1.35/条。Seedance 的实验预算继续使用当前账户一次成功任务得到的每秒 token 消耗进行线性估算，并明确标记为中等置信度；最终成本必须以火山账单为准。

## 固定实验矩阵

实验包含三类 6 秒镜头：

1. 商品静态展示：测量商品轮廓、颜色、结构、清晰度与伪文字；
2. 人物情绪表演：测量人物身份、表情自然度、视线与轻动作稳定性；
3. 手部商品交互：测量手部物理、商品结构与动作因果连续性。

每类镜头为 Seedance 和 MiniMax 各准备一个任务，共 6 个视频任务。手部交互镜头需要额外生成一张同时包含商品、人物和场景的复合关键帧。

正式执行需要同时满足：

1. 商品、人物和场景素材完整；
2. 至少一个视频供应商已配置；
3. 实验已使用逐字一致的审批短语批准；
4. 批准预算不低于 ¥19.40；
5. 实验状态明确变为 `approved`。

生成实验清单、查看报告或进入前端预算页都不会产生 API 费用。

## 数据记录

每个实验任务已经预留以下真实指标：

- 提交时间、完成时间与总延迟；
- 预计费用和实际费用；
- 自动质检分数、是否自动通过；
- 人工盲审分数、是否人工通过；
- 失败分类；
- 云端任务 ID、本地产物路径和错误信息。

盲审结果只有在任务完成后才能写入，防止对未生成的样本提前评分。

## 新增接口

- `POST /api/projects/{project_id}/benchmarks`：只准备实验与预算；
- `GET /api/projects/{project_id}/benchmarks/latest`：读取最近实验，没有时返回 `null`；
- `POST /api/projects/{project_id}/benchmarks/{experiment_id}/approve`：校验审批短语和预算；
- `POST /api/projects/{project_id}/benchmarks/{experiment_id}/jobs/{job_id}/review`：记录人工盲审。

本阶段没有增加自动提交付费实验的按钮。付费执行器应在用户确认具体预算后再启用。

## 前端改进

模型路由页新增供应商实验预算卡，显示：

- 实验状态；
- 预计费用和硬预算上限；
- 计划任务数；
- 三类测试镜头及其阻塞原因；
- 正式执行需要使用的审批短语。

系统现在优先打开同时具备商品、人物和场景素材的项目，避免早期空测试项目遮挡真实生产项目。
