# FrameFlow 第四阶段优化记录（2026-07-29）

## 阶段目标

第四阶段将视觉质检从“输出一个分数”升级为“输出可以执行的修复决策”，并把镜头成功率、重试次数和真实成本连接成可观察的生产闭环。

## 结构化失败分类

当前支持以下失败类型：

| 分类代码 | 含义 | 默认修复方向 |
| --- | --- | --- |
| `product_identity` | 商品外形、颜色或核心结构变化 | 加强商品参考，优先重做关键帧 |
| `character_identity` | 人脸、年龄、发型或服装变化 | 强化人物身份约束 |
| `scene_continuity` | 房间结构、光线或空间不连续 | 锁定场景结构与光线方向 |
| `hand_physics` | 手指、肢体、遮挡或商品交互错误 | 简化为单一动作，减少遮挡 |
| `story_mismatch` | 镜头没有完成叙事动作 | 重写镜头起点、动作和终点 |
| `extra_people` | 出现多余人物或重复人脸 | 限定人物数量 |
| `camera_gaze` | 人物不自然地直视镜头 | 改为注视商品或动作目标 |
| `text_watermark` | 生成乱码、文字或伪水印 | 禁止模型生成文字，文字留给后期 |
| `low_visual_quality` | 模糊、闪烁、跳变或不稳定 | 强化主体稳定与清晰度 |

## 修复决策

每个关键帧或视频审核节点现在会保存：

- 质量分数与严重程度；
- 失败分类；
- 可执行的修复动作；
- 下一次生成需要追加的提示词补丁；
- 建议的备用供应商；
- 剩余重试次数；
- 已花费成本、预计下次成本和默认预算上限；
- 是否建议局部重试。

局部重做生成节点时，系统会自动读取上一次审核产生的提示词补丁。它不会自动提交付费任务，用户仍需在界面明确确认费用。

## 重试和成本门控

默认每个付费生成节点允许初次生成加两次重试。预算按以下方式计算：

`节点默认预算 = 单次预计费用 ×（1 + 最大重试次数）`

达到次数或费用上限后，API 默认拒绝继续执行。用户只有在检查质检报告后明确覆盖预算，才能再次提交。这一设计避免错误镜头在后台无限重试并持续扣费。

## 项目质量基准

新增接口：

`GET /api/projects/{project_id}/quality-report`

报告按供应商和生成类型统计：

- 生成尝试次数；
- 已审核产物数；
- 自动通过数量与通过率；
- 实际累计成本；
- 单次生成平均成本；
- 各类失败原因出现次数。

前端生产工作流页已增加 `QUALITY BENCHMARK` 面板。当前持久项目中显示的 `demo` 数据来自早期快速预览，只用于验证统计链路，不代表 Seedance 或其他正式供应商的质量。

## 工作流升级

工作流版本已升级到 `frameflow-dag-v4`。旧项目会保留缓存指纹相同节点的产物、审核状态、尝试历史和成本，并自动增加质量决策字段。

## 验证结果

- 后端自动化测试：22 项全部通过；
- 前端 TypeScript 和 Vite 生产构建通过；
- 本地浏览器冒烟测试通过，无控制台错误；
- v3 项目无损迁移至 v4；
- 质量基准接口返回真实持久化尝试数据；
- 本阶段没有调用付费生成 API。

## 下一阶段建议

第五阶段应建立正式供应商小样本基准实验，而不是继续凭主观感觉选择模型：

1. 选择 3 类镜头：商品静态展示、人物情绪表演、手部商品交互；
2. 每类镜头使用相同首尾帧和提示词，分别在已接入供应商上生成少量样本；
3. 使用当前视觉质检体系评分，并由人工盲审复核；
4. 记录真实费用、等待时间、自动通过率和人工通过率；
5. 根据实验结果更新路由规则，使不同镜头自动选择性价比最高的模型；
6. 所有正式样本生成前先输出预计总费用并等待用户一次性确认。
