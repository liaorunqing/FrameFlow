# Phase 12：多项目与品类稳定性基线

日期：2026-08-10

## 本阶段目标

将 FrameFlow 从单一测试项目升级为个人可持续使用的多项目工作台，并为玩具、数码、日用品三类广告提供互不污染的创作基线。本阶段只建立项目、素材事实和零成本预检，不主动提交任何付费图像或视频任务。

## 已完成

- 顶部新增项目切换器，可在已有项目间切换，并恢复各自的故事、工作流与交付状态。
- 新增“新建项目”入口和三类模板：玩具故事、数码体验、日用好物。
- 模板预设 30 秒、9:16、抖音目标，并分别提供适合品类的受众、卖点、视觉风格与叙事简报。
- 创建项目后始终从素材阶段开始，不继承其他项目的素材、镜头、审核或成本。
- 素材页新增商品品类字段和零成本预检。商品事实图为进入规划的硬条件；人物、场景参考为跨镜一致性建议。
- API 创建方法由固定默认值升级为可传入模板参数，同时保留安全默认值。
- 新建项目界面明确提示当前操作不会提交付费生成任务。

## 验证结果

- 前端生产构建：通过。
- 后端回归测试：51 passed。
- Playwright 冒烟测试：通过；覆盖四步导航、项目模板弹窗、三类模板和控制台错误检查。

## 下一阶段

为数码和日用品各准备一套真实素材，通过“素材分析 → 故事规划 → 关键帧 → 五段视频 → 后期合成”的相同流程运行零成本预检与小规模实测。只有上传真实商品素材后才进入外部生成调用，并继续按项目独立记录成功率、重试次数和实际成本。
