# 阶段 7：零生成费用的本地成片样片

## 目标

在不再调用视频、图像或付费语音 API 的前提下，验证系统能否把既有的合格镜头组织成可播放、可审阅的广告样片。

## 实际输出

- 成片：[benchmark-story-sample.mp4](../backend/data/benchmark-artifacts/74f95b1b-8eda-445a-bb05-18efeb3fe420/local-assembly/benchmark-story-sample.mp4)
- 时长：15.00 秒
- 画幅：720 × 1280（9:16）
- 音频：本地 Windows 语音合成的 WAV 旁白 + 粉噪声环境声桥
- 字幕：SRT 时间轴烧录
- 收尾：品牌 Logo、CTA 与产品名叠加在最后一个商品镜头上

## 镜头选择

此成片是“本地剪辑样片”，不是已验证的完整多镜头生产成片。它按当前三段脚本的叙事顺序选择基准实验中人工复核评分最高的镜头：

1. 人物情绪：`character_emotion:minimax-official`（92 分）
2. 手部互动：`hand_interaction:minimax-official`（76 分）
3. 商品展示：`product_showcase:seedance-official`（93 分）

这样保留了“人物 → 动作 → 商品结果”的基本因果顺序，但不把原本用于 A/B 对照的其他片段强行塞进故事。

## 剪辑器强化

`compose_campaign` 已具备：

- 项目比例标准化和帧率统一；
- 本地旁白、字幕和连续环境声桥；
- 可用剩余时长时生成独立 CTA 片尾；
- 没有片尾余量时，在最后镜头创建透明 CTA 面板；
- CTA 出现期间将字幕上移到安全区域，避免文字与品牌面板重叠；
- FFmpeg 输出 H.264/AAC、`faststart` 优化，适合浏览器直接预览。

## 产品入口

模型路由页现在提供“本地编辑样片”卡片。只要实验至少有三条成功视频，用户可点击“合成本地样片”；已合成时显示“打开本地样片”。接口只读取本地已下载文件并运行 FFmpeg，不会调用生成模型。

## 验收

- 样片真实生成并通过 `ffprobe`：15.00 秒，720×1280，含视频和音频流。
- 末帧人工视觉检查：CTA 与字幕安全区不再重叠。
- 浏览器回归：本地样片入口和 MP4 静态访问通过。
- 后端测试：32 项通过。
- 前端生产构建：通过。

## 限制与下一步

该样片验证的是后期生产管线，不证明三条基准镜头已经具有真正的跨镜头连续性。下一轮付费实验前，应先使用严格画幅的共享关键帧，为每一个故事镜头生成有首尾帧约束的视频，再用这套已验证的后期链合成正式广告。
