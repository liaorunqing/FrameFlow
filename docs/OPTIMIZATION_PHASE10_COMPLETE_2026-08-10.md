# 视频系统第十阶段改造完成报告

日期：2026-08-10  
工作流版本：`frameflow-dag-v6`

## 本阶段完成内容

1. 产品身份锁定：新增不可变身份包，复制原始商品素材、记录 SHA-256、尺寸和透明通道状态。系统禁止自动抠图；只有真实 Alpha 素材可直接合成，其他商品图只用于生成条件与质检，避免毛绒边缘被错误抠除。
2. 提示词与风险路由：每镜头采用故事状态、单一动作、摄影机、连续性、商品锁定、物理约束、交接和负向约束八段式提示词。人物/手部/商品交互镜头标记为高风险并建议双候选。
3. 候选选择：新增不触发 API 的候选评分器。商品一致性占 40%，自动质量占 40%，手部物理占 20%；故事不匹配、内部异常切镜或文件缺失直接淘汰，最终仍需人工终审。
4. 功能状态：新增 AI 对话、口语练习、词典状态时间轴，作为后期文字叠加，不让视频模型生成文字。旧项目乱码记录提供受控的五镜头语义回退。
5. 屏幕跟踪：新增基于 OpenCV 模板匹配的 ROI 跟踪器。必须由已批准 ROI 启动；置信度低于阈值时回退固定安全区，禁止叠加层漂移到人脸。
6. 字幕：移动端字幕字号提升，并将长旁白拆成分时字幕，再按十个中文字符平衡换行，解决上一版字体过小和初次放大后越界的问题。
7. 声音：正式接入 Shotcraft 授权音频资产，加入整片 BGM、镜头动作衔接、CTA impact 和品牌 sparkle；旁白、环境底、BGM、SFX 统一混音并执行 -16 LUFS / -1.5 dBTP 标准化。
8. CTA：主文案最小 44px、辅助信息最小 32px，品牌停留 2.8 秒；Logo、型号和 CTA 始终只在后期叠加。

## 零新增 API 费用回归

- 输入：已有 5 段 MiniMax 海螺镜头。
- 输出：`campaign-master-v2-post.mp4`。
- 规格：720×1280、24fps、30.000 秒、H.264 + AAC 48kHz mono。
- 响度：约 -15.44 LUFS，True Peak 约 -1.44 dBTP。
- 静音检查：-45 dB、0.8 秒阈值未发现长静音段。
- 自动化测试：51 项全部通过。
- 新增 API 成本：¥0。

## 仍受底层生成素材限制的部分

本阶段后期改造不能修复已有生成镜头中的人物脸型变化、商品毛色漂移、挂绳位置变化、手部物理错误和极端贴脸构图。新工作流会通过身份包、共享真实末帧、高风险双候选和局部重做降低这些问题，但正式商业投放仍必须对新生成的镜头执行人工终审。
