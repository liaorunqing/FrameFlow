# FrameFlow 双镜头故事连续性实验

日期：2026-07-29

## 实验目标

验证“Seedream 共享边界关键帧 + Seedance 1.0 Pro 首尾帧视频 + FFmpeg 动作匹配剪辑”能否生成一条人物、商品、场景和故事状态连续的10秒广告。

## 微故事

同一位少年站在明亮玻璃长廊，准备带小羊手偶去探望重要的人。他原本略微紧张，通过让手偶点头练习问候，逐渐放松；听到画外脚步后，他转身并让手偶轻轻挥手。

## 实际执行

1. Seedream 4.5 使用商品、人物、场景三张参考图，一次生成3张连续关键帧。
2. 人物、服装、场景和光线连续，但第3张将小羊手偶错误地生成成白色手套。
3. 成本门禁阻止了视频提交，只针对第3张关键帧进行一次局部修复。
4. 修复帧恢复了商品的圆脸、黑眼、粉鼻、棕角、白色绒毛和银点腹部。
5. Seedance 1.0 Pro 分别生成关键帧1→2、关键帧2→修复帧3两段5秒视频。
6. 比较了硬切与0.167秒短叠化，最终选择硬切。

## 结果

- 两段视频均为1920×1088、24 FPS、H.264。
- 每段时长5.04秒，最终硬切版本10.08秒。
- 每段使用246,840 tokens，总计493,680 tokens。
- 镜头一实际尾帧与镜头二实际首帧几乎一致。
- 人物身份、白色外套、玻璃长廊和左侧窗光跨镜头稳定。
- 小羊手偶在视频阶段保持稳定，没有再次变成手套。
- 故事状态呈现为“低头迟疑 → 举起手偶并放松 → 转头并挥手”，具备可感知的因果推进。
- 硬切没有明显空间跳变；叠化产生轻微重影，因此不采用。

## 成本

- Seedream 4.5：4张图片，刊例估算1.00元；当前账号免费额度可能覆盖。
- Seedance 1.0 Pro：493,680 tokens。
  - 按15元/百万tokens：约7.41元。
  - 按7.50元/百万tokens企业优惠：约3.70元。
- 含图片的实验总成本区间约3.70–8.41元，最终以控制台账单和免费额度抵扣为准。

## 关键发现

1. **先生成关键帧能有效拦截昂贵错误。** 本次第3帧商品错误在视频提交前被发现，只需重做一张图片。
2. **组图不能保证每张商品都正确。** 即使人物和场景高度连续，商品仍可能在单张边界帧中变形，因此必须逐张质检。
3. **共享边界帧能解决接缝。** 同一张关键帧既是镜头一目标尾帧，又是镜头二输入首帧，实际接缝接近连续拍摄。
4. **自然硬切优于统一模板转场。** 当动作、构图和光线匹配时，硬切比叠化更像真实影视剪辑。
5. **提示词必须写可拍摄动作。** “先用眼神注意、再转头、最后挥手”比“开心展示产品”更容易形成真实表演。

## 下一步工程改进

- 增加视觉理解/质检模型，自动识别商品变形、人物漂移和手部错误。
- 将关键帧审核做成正式 API 状态机：计划、生成、审核通过、局部重做、批准计费。
- 将每个 Seedance 任务 ID、usage 和实际尾帧写入项目数据库，支持断点续跑。
- 编辑器默认使用动作匹配硬切，只在时间跳跃或场景变化时建议叠化。
- 增加整片旁白、环境声、音乐和后期 Logo/字幕时间线。
