# 阶段 8：品牌真相库与匿名盲审

## 目标

把系统从“根据素材生成”推进到“受品牌事实约束地生成”，同时把供应商实验从工程人员评分推进到匿名人工盲审数据。

## 1. 品牌 / 商品真相库

新增 `BrandBible`，由以下四类事实组成：

| 对象 | 内容 |
| --- | --- |
| 商品 | 参考素材、不可改变的轮廓/颜色/结构、必须呈现的卖点、禁止变化 |
| 人物 | 身份、脸部、年龄感、发型和服装的连续性约束 |
| 场景 | 空间结构、主要物件、光线方向约束 |
| 品牌 | Logo、价格和 CTA 仅由确定性后期叠加的规则 |

真相库有 `draft` 与 `approved` 两种状态。草案可在素材页核对，但不会进入生产提示词；只有人工批准后，系统才会把约束写入关键帧和视频提示词。这避免未经确认的自动识别结果污染后续付费生成。

当前项目已建立一份草案，尚未批准。

## 2. 匿名盲审

新增匿名样本接口与界面。盲审卡片仅显示：

- 视频；
- 镜头类型；
- 质检维度；
- 人工分数滑块和通过/不通过选择。

它不会显示供应商、模型名、自动分数或成本。提交分数后才会写入实验记录。这样积累的数据可用于校准本地视觉质检器，并避免“预先知道模型”造成的评分偏差。

当前已有一个匿名样本被加载到界面，但没有提交任何人工评分。

## 3. 生产链影响

批准后的真相库会被 `build_production_plan` 注入到关键帧的 `required_subjects`，因此会自动继承到关键帧提示词和视频连续性约束中。它不会改变已完成的实验结果，也不会触发任何外部调用。

## 验收

- 后端测试：34 项通过。
- 前端生产构建：通过。
- 浏览器验收：真相库草案卡片、批准入口、匿名盲审视频卡片和隐藏供应商信息均通过。

## 下一阶段

在你核对并批准真相库、完成至少 3 个匿名镜头评分后，下一阶段应建立“镜头基准集”：把每个样本的首帧、抽帧、失败类型、人工分数、供应商、成本和重试次数标准化导出。之后才能用这些数据校准自动质检阈值，并设计第一轮真正使用共享首尾关键帧的 30 秒广告实验。
